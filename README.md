# ISP AI Monitor

Site do projeto de Inteligência Artificial Aplicada (LIAA, UNIPAMPA, 2026/2) de Matheus Mayer:
detecção antecipada de quedas de clientes de fibra óptica num provedor regional.

https://liaa-matheusmmayer.github.io

Os números vêm dos experimentos do sistema ISP AI Monitor (`data.js` é gerado automaticamente).
Nenhum dado de cliente é publicado: as ONUs aparecem só por código.
